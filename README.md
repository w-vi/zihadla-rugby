# Žihadla Židlochovice – web

Statický web rugbyového klubu Žihadla Židlochovice, nasazený na [zihadla-rugby.cz](https://zihadla-rugby.cz) přes GitHub Pages.

## Struktura

- `index.html`, `oddil.html`, `rugby.html`, `trenink.html` – stránky webu (Bootstrap 5)
- `css/styles.css`, `js/scripts.js` – styly a skripty
- `assets/` – obrázky a favicon
- `plakat.jpg`, `plakat2.jpg`, `plakat3.jpeg` – plakáty
- `CNAME` – doménová konfigurace pro GitHub Pages
- `LICENSE` – GPLv3

## Nasazení

Push na větev `main` automaticky publikuje web přes GitHub Pages.
